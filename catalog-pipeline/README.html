Repo Catalog

Append-only raw repo observations plus identity resolution.

  • raw/: append-only JSONL rounds. Historical import is round-0000.jsonl.
  • identity/: SQLite identity store keyed by GitHub node ID when known, otherwise provisional normalized URL hashes.
  • staging/: future promotion candidates, empty in Phase 2.
  • curated/: future gated curated sink, empty in Phase 2.

Never delete raw observations. Dedupe is represented by identity and provenance rows, not by overwriting history.
